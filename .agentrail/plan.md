# Saga plan: linear algebra foundations

Purpose: prove the repository's complete teaching/test/visual contract while
delivering the first coherent vector-geometry unit, LA01-LA06.

## Steps

1. **Repository and capability baseline** — establish thin `just`/script
   entry points, native mlplunit discovery and shared assertions, catalog and
   documentation checks, authored/generated web layout, and pinned binary
   selection. Execute minimal probes for `dot`, rank-2 and higher-rank
   `matmul`, reshape/transpose/axis reductions, labels, static include, and web
   statement behavior. Replace candidate capability claims with observed
   evidence; do not implement upstream changes.
2. **Vectors and array laws** — implement LA01 with addition/scaling laws,
   dimension mismatch and zero/singleton cases, CLI narration, and the first
   standalone vector visual using the required prolog/epilog anatomy.
3. **Dot product and alignment** — implement LA02 from elementwise products
   and reduction, use `dot` as an oracle, visualize aligned/orthogonal/opposed
   vectors and row-column accumulation, and state the finite-test boundary.
4. **Norm, distance, and normalization** — implement LA03 with a shared
   approximate-equality contract, zero-vector policy, scale and triangle
   fixtures, and geometric visuals that remain meaningful without animation.
5. **Cosine embedding similarity** — implement LA04 with deterministic small
   embedding fixtures, golden similarity/ranking results, magnitude-invariance
   and zero-vector cases, and an ML retrieval explanation.
6. **Span, orthogonality, and projection** — implement LA05-LA06 with linear
   combinations, dependent-basis and zero-denominator witnesses, projection
   reconstruction plus orthogonal-residual checks, and a basis/shadow visual.
7. **Foundation curriculum integration** — run the full repository gate;
   audit lesson naming, comments, prologs/epilogs, numerical claims, visual
   fallbacks, generated previews, syllabus/catalog links, and capability
   evidence. Publish an acceptance report and reconcile the matrix saga from
   what the runtime actually demonstrated.

## Acceptance

- `just check` runs native mlplunit plus structural, docs, demo, and generated
  web checks through portable scripts.
- LA01-LA06 are deterministic, self-checking, and navigable as one learning
  unit in CLI and browser forms.
- Approximate comparisons state tolerance and include a test just outside it.
- Every committed preview is generated by the corresponding demo and checked
  for freshness.
- Capability and blocker claims cite executable probes against the configured
  interpreter version; unsupported later lessons remain constrained.
- Each step updates tests, lesson/catalog/syllabus docs, and AgentRail state in
  the same commit before `agentrail complete`.
